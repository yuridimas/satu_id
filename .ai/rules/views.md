# Views

## Flux color semantics for alerts, badges & buttons
Flux color codes (Tailwind palette names): `green`=success, `orange`=warning, `rose`=error, `blue`=info. Use on `flux:callout`, `flux:badge`, and any alert/tone. Flux button variants: submit/primary=`indigo`, back/secondary=`zinc`, link/href=`purple`. Keep these semantics consistent across all pages.
